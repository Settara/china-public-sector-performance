Показатель 40. Заполнение пропусков исходной мощности переработки отходов
Дата: 12.11.2026.

1. ИСХОДНЫЕ ДАННЫЕ И ФОРМУЛА ПОКАЗАТЕЛЯ
Название показателя в основной книге и в статье научного руководителя не изменено.
40.xlsx, Sheet1: Capacity for Harmless Wastes Treatment (ton/day), мощность обработки отходов, тонн в сутки.
Показатель на одного жителя = мощность, т/сутки / (население в единицах 10000 человек * 10000).
Источник населения: ../01_lighting/population.xlsx, Sheet1, тот же регион и тот же год.
Таким образом, результат измеряется в т/сутки на одного жителя.
Пример для 2011 года Тибета: мощность из 40.xlsx!Sheet1!O30 делится на population.xlsx!Sheet1!O30 * 10000.
Сначала восстановлена исходная мощность; относительный показатель отдельно не заполнялся и должен пересчитаться по исходной формуле основной книги.

2. ОБЛАСТЬ ЗАПОЛНЕНИЯ
Изменен файл 40.xlsx, Sheet1, строка 30 (Xizang / Тибет).
Заполнены только K30:O30: 2015, 2014, 2013, 2012, 2011 годы.
Все пять ранее пустых ячеек выделены светло-зеленой заливкой #C6EFCE.
В них записаны формулы, а не текстовые числа. На экране два знака после запятой, в вычислениях полная точность.
Остальные исходные значения, названия, листы и ячейки сохранены.
Пропуски до 2011 года оставлены без изменений. Число за 2007 год используется только как опорное наблюдение для оценки.
Добавленные данные являются расчетными оценками; это не официальные наблюдения НБС КНР.

3. МЕТОД: ЛИНЕЙНАЯ ИНТЕРПОЛЯЦИЯ
Ближайшее известное значение до разрыва: 2007 год, S30 = 400 т/сутки.
Ближайшее известное значение после разрыва: 2016 год, J30 = 1151 т/сутки.
Между 2007 и 2016 годами девять годовых интервалов.
Средний годовой абсолютный прирост = (1151 - 400) / (2016 - 2007) = 751/9 = 83,444444444444 т/сутки в год.
Для года t: A(t) = 400 + (1151 - 400)*(t - 2007)/(2016 - 2007).
Это равномерное увеличение в абсолютных единицах, а не одинаковый процентный рост.
Для 2011 года: 400 + 751*(2011-2007)/9 = 733,777777777778 т/сутки.
Для 2012 года: 400 + 751*(2012-2007)/9 = 817,222222222222 т/сутки.
Для 2013 года: 400 + 751*(2013-2007)/9 = 900,666666666667 т/сутки.
Для 2014 года: 400 + 751*(2014-2007)/9 = 984,111111111111 т/сутки.
Для 2015 года: 400 + 751*(2015-2007)/9 = 1067,555555555556 т/сутки.
Опорные годы закреплены в формулах: изменение одного восстановленного года не меняет остальные; изменение исходных опорных наблюдений пересчитывает все пять оценок.

4. ДОПУЩЕНИЯ И ОГРАНИЧЕНИЯ
Полный разрыв в исходном ряду охватывает 2008–2015 годы, то есть восемь отсутствующих годовых наблюдений. В исследуемом периоде 2011–2024 заполнены только пять из них.
Метод предполагает плавный рост между двумя известными точками. Фактический ввод мощностей мог происходить скачками, что по имеющимся данным восстановить нельзя.
Длинный интервал повышает неопределенность. Эти оценки следует учитывать при проверке устойчивости сводных индексов и индексов Морана.
В исходнике есть примечание: с 2011 года данные об обработке компостированием не собираются отдельно; с 2017 года не собираются соответствующие данные об экскрементах и моче. Эти примечания сохранены; сопоставимость ряда в переходные годы полностью не подтверждена.
Поскольку опорные годы 2007 и 2016 расположены по разные стороны примечания 2011 года, возможное изменение статистического учета — дополнительное ограничение интерполяции.
Не использовались значения соседних провинций, чтобы напрямую не создавать искусственное пространственное сходство для Морана.
Если появятся сопоставимые официальные данные, расчетные формулы нужно заменить такими данными и обновить этот журнал.
Исходный источник наблюдений: National Bureau of Statistics of China, https://data.stats.gov.cn/
